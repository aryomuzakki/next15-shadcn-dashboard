## Getting Started

1. Clone this project :

```bash
git clone https://github.com/aryomuzakki/nextjs-dashboard
```

2. Copy `.env.example` file into `.env` file, edit `JWT_SECRET` environment variable with your secret key

3. Install dependencies with npm, yarn, pnpm, or bun

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

4. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

1. Open [http://localhost:3000](http://localhost:3000) in a browser to see the result.
